# Color reference

Pastel washes on drop zones. Soft CTA gradients (`500 → 400`, not `600`).

## By file type

**PDF** → rose · `converter-main-card-rose`  
**DOCX** → blue · `converter-main-card-blue`  
**Image** → purple · `converter-main-card-purple`  
**PPTX** → orange · `converter-main-card-orange`  

→ `lib/format-tone.ts` (`FORMAT_TONE`)

## Flagship only

**Word to PDF** → blue · home `converter-card-blue` · CTA `converter-cta-blue`  
**PDF to Word** → rose · home `converter-card-rose` · CTA `converter-cta-rose`  

## Tools index (`/tools`)

**Core converter cards** → pastel wash (blue / rose)  
**Utility cards** → white + `glass-subtle`  
**All tools view** → grouped blocks: PDF → DOCX → PPTX → Image  

## Code map

**All tones** → `components/tools/tone-styles.ts` (`TONE_STYLES`)  
**Format → tone** → `lib/format-tone.ts`  
**Workspace / index helpers** → `components/tools/tool-theme.ts`
